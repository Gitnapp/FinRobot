# UI 与请求规则

## 组件归属

| 行为 | 唯一实现 | 使用范围 |
| --- | --- | --- |
| 功能区/子页面名称 | `src/app/navigation.ts` | 侧栏、顶栏、面包屑 |
| 跳转标题与箭头 | `NavigationLink` | 标的卡片、宏观卡片、侧栏标题；长标题末词和箭头一起换行 |
| 选择器、状态筛选、搜索 | `FilterToolbar` | 市场、跟踪、报告、调试；搜索最大 320px，窄屏自动折行 |
| 双栏的开关、过渡、滚动 | `SplitView` / `usePreviewSelection` | 市场页；关闭过程禁止交互，结束后卸载右栏 |
| 标的预览内容 | `MarketPreview` | 只消费当前标的的数据；不管理页面列宽 |
| 加载/刷新失败 | `AsyncContent` / `RefreshNotice` | 首次无数据使用局部加载；已有数据时刷新失败只显示提示，不清空内容 |
| 标签页的选中指示 | `AnimatedSwitcher` | 测量实际按钮宽度，负责唯一的滑动指示，不再使用额外伪元素下划线 |
| 标的卡片 | `CoverageAssetCard` + `styles/cards.css` | 四周 16px，间距 24px；不强制等高 |

`styles.css` 保留基础与未拆出的业务页面样式。导航、卡片、切换、筛选、预览、分栏、加载各自有唯一 CSS 文件；不要在全局文件尾部覆盖这些组件。修改现有规则，不重复声明同一选择器。响应式与减少动效规则放在对应组件文件。

布局尺度来自 design tokens：`search-control-width`、`card-grid-gap`、`compact-card-padding`、`navigation-motion-duration`、`panel-motion-duration`。只有明确的新页面跳转入口启用箭头动效，下拉框、返回与模态框不启用。

## 请求归属

- `src/api/client.ts`：HTTP 读写、30 秒超时、取消信号、结构化 HTTP 错误。统一 `no-store`，避免浏览器缓存再叠一层。
- `src/api/query-policy.ts`：React Query 的缓存、轮询、失败重试及失效范围。页面和组件只定义 key、请求及 enabled，不自行声明计时参数。
- 所有 queryFn 将 React Query 的 `signal` 传入 `api`。快速切换标的或卸载最后一个订阅者时取消旧请求。共享请求仍由剩余订阅者消费。
- 修改操作不自动重试。用 `useRefresh(domain)` 只使相关数据失效，修改设置不会重刷整个行情列表。

| 前端数据 | 新鲜期 | 可见页轮询 |
| --- | --- | --- |
| 自选、详情、跟踪 | 15 秒 | 30 秒 |
| 行情历史、宏观、财务、同业、模型/假设、披露与线索 | 30 秒 | 正常 60 秒；后台快照生成中 1.5 秒 |
| 服务设置、自选分组、代码搜索 | 5 分钟 | 不轮询；过期后重新进入/聚焦/重连更新 |
| 散户情绪与催化信息 | 15 分钟 | 15 分钟 |
| 报告列表 | 15 秒 | 有活动任务 1.5 秒，否则 15 秒 |
| 报告正文 | 5 分钟 | 终态停止；活动态 1.5 秒 |
| 任务 | 0 秒 | 活动态 1.5 秒，任务中心空闲 15 秒；终态详情停止 |
| 数据源健康 | 5 分钟 | 5 分钟 |
| 调试 | 0 秒 | 当前页签 5 秒；旧日志页停止 |
| 日历分页 | 30 秒 | 仅正在生成快照时 1.5 秒 |

离开可见标签页时停止普通轮询，只有持久任务状态继续后台轮询。未使用的缓存 30 分钟后回收。认证/参数/限流等 4xx 不自动重试；普通网络错误与 5xx 最多重试一次；主动取消和超时不重试。

## 旧数据与服务端缓存

浏览器 staleTime 表示“是否需要再次询问服务端”，不代表数据源更新时间。服务端规则在 `finrobot_equity/research_desk/cache_policy.py`：

| 数据源/快照 | TTL | 失败时旧数据保留范围 |
| --- | --- | --- |
| 日行情源 | 5 分钟 | Yahoo 保留最近有效缓存至过期后 2 天 |
| 行情组合 | 1 分钟 | 过期后 1 天 |
| 跟踪行情快照 | 1 分钟 | 距成功抓取 2 天 |
| FRED / 一般资料 | 6 小时 | 距成功抓取 7 天 |
| 日更宏观 | 1 天 | 7 天 |
| 当周日历 / 历史月份 | 1 天 | 2 天 / 30 天 |
| 披露 | 1 天 | 30 天 |
| 研究线索 / 同业发现 | 7 天 | 30 天 |
| 同业行情 | 15 分钟 | 7 天 |
| 财务 | 日跟踪 1 天、周跟踪 7 天、未跟踪 6 小时 | 366 天 |
| 情绪/催化信号 | 6 小时 | 7 天 |

快照刷新失败不覆盖 payload 或成功时间；失败后至少等待 15 分钟再尝试。缩短 TTL 时用 `fetched + ttl` 立即判断是否过期，不再由业务层额外修改缓存表。底层行情源返回旧数据时携带 stale 标记，数据抽象层和跟踪卡片不会把它包装成新数据。任务执行与共享后台快照独立于浏览器页面生命周期，取消读取不会取消已入队任务。

## 验证

- `pnpm --filter @garage/research-desk test`：请求取消、缓存复用、旧数据保留、定向失效、后台轮询及布局行为。
- `pnpm build`：类型检查与产物构建。
- `.venv/bin/python -m pytest tests/desk -q`：缓存、报价、任务、财务、配置及模型接口回归。
- UI 检查市场独立滚动、侧栏反复开关、跟踪卡片留白、宏观卡片加载尺寸，以及 390px 窄屏布局。

## 详情卡片分页

详情页由 `styles/detail-cards.css` 控制 Bento 网格：桌面价格图/日历440px（8:4列），综合指标/情绪380px（8:4列），同业/财务来源420px（6:6列），线索320px、新闻380px（6:6列）。研究观点与估值360px，报告400px，模型按完整表格内容展开。窄屏转单列并按类型设置高度，加载和空状态保留同类型尺寸。

`CardPagination` 使用组件库 Pagination 与 Button；`useCardPage` 管理页码、条目切片、标的/筛选变更时重置，以及列表缩短时校正页码。报告4条、披露4条、同业4条、线索6条、财报来源2条；模型在同一张卡片中完整展示，不分页。页脚始终预留空间；单页不显示控件。增加内容时分页，不用内部竖向滚动或overflow裁切遮蔽内容。

财务概览与价格趋势在详情中使用 FinancialPricePanel 合并展示，复用两个指标组件，避免各占一张固定高度卡片。

## 异步操作模式

`useSubmitTask` 是前端统一入口：只等待持久化回执，更新任务中心，不发起页面跳转。添加弹窗保留搜索与分组，条目右侧为加号，排队后显示准备中；只有用户点击查看才打开详情。

`POST /api/tasks` 接受 research、add_asset、track_asset、refresh_asset。报告继续使用报告记录承载其领域状态；通用数据操作由 SQLite task_queue 持久化，并通过同一 Tasks API 合并展示。数据操作与长报告在独立执行通道运行，避免报告撰写阻塞添加；没有新增消息中间件。

TaskDefinition 只定义标题和幂等阶段；TaskQueue 统一负责事务领取、活动任务去重、阶段持久化、超时、失败、同ID重试及重启恢复。新增操作注册阶段，不在前端拼接多个长请求。资产准备阶段通过 DataAccess 获取行情、财务、同业、披露、资料线索和情绪。缺失资料单独记录 warnings，支持重试，不制造数据。

任务中心在阶段变化时刷新相关缓存，在完成或失败时通知；列表和详情页通过 AssetPreparation 展示准备状态。任务执行与弹窗、页面生命周期无关。已加入的分组在数据阶段失败后保留，重试不产生重复成员。

页面进入统一使用200ms透明度淡入，不使用整页位移或缩放。宏观图表首次从占位变为内容时同样淡入，尺寸保持固定。面包屑保留悬停展开和独立的轻微路径淡化（360ms，透明度0.82至1，无位移），不跟随页面透明度渐入；后台轮询不会反复触发整页动画。尊重prefers-reduced-motion。

## 数学曲线加载

MathCurveLoader 使用 Math Curve Loaders（https://paidax01.github.io/math-curve-loaders/）展示的曲线族作为视觉参考，以独立 SVG 参数曲线实现拖尾效果。每次挂载随机一种，加载期间保持不变；减少动态效果时静止显示。LoadingState 在所属区域几何中心放置图形，说明文字置于其下方，不改变中心位置。initial 模式超过2秒显示耗时说明，refresh 模式只显示动画。历史研报正文和任务信息并行读取。
